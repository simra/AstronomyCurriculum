Motivating evidence

The equation is a dynamical bookkeeping statement: each component redshifts differently and therefore dominates at a different epoch.

Cosmological claims are indirect: an observable is calibrated, placed in a model, and compared against alternatives. Keep those layers separate throughout the lecture.

Physical framework

Start from the governing relation and define its domain:

\(H^2(a)=H_0^2[\\Omega_r a^{-4}+\\Omega_m a^{-3}+\\Omega_k a^{-2}+\\Omega_\\Lambda]\)

State the coordinate choice, units, boundary conditions, and approximation before substituting numbers. The same symbol can mean a different quantity in Newtonian, special-relativistic, and expanding-space contexts.

Worked calculation

rho_crit = 3H0^2/(8 pi G) = 1.260744e+11 solar masses Mpc^-3.

The density is an energy-density scale; Omega values compare each component with this critical value.

Estimate the scale first, then check dimensions and comparative direction. The displayed value is generated from shared ASTR420 constants and data.

Evidence versus inference

  • Raw data are not the same as calibrated observables.
  • A fitted parameter is conditional on the likelihood, prior, and selection function.
  • Independent probes can agree because the model is useful, or disagree because an assumption is hidden.

Boundary condition

Limit of the model: The density is an energy-density scale; Omega values compare each component with this critical value.

Ask what happens if the dominant assumption fails. In cosmology, approximation honesty matters because distances, times, and abundances accumulate model dependence.

Active reasoning

Prompt: Evaluate the present critical density from H0 and compare matter and dark-energy contributions.

Predict the direction before calculating. Then name one observation that could discriminate between two explanations.
