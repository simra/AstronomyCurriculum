Problem and physical meaning

A computation is an experiment with a model, finite precision, data, and a falsifiable check. IEEE-754 arithmetic rounds every operation; cancellation and conditioning can make a small input perturbation large relative to the desired answer.

Error budget and limitations

Machine precision is not the same as scientific accuracy. A stable calculation can still solve a misspecified physical model.

Classify each uncertainty before combining terms: local/global solver error, timestep or spatial discretization, Monte Carlo sampling, parameter uncertainty, measurement uncertainty, and model discrepancy are not interchangeable. Conservation can test internal consistency but does not prove the model is physically complete.

Misconceptions to avoid

  • More displayed digits do not imply more physical accuracy.
  • A successful solver exit or smooth plot does not establish convergence.
  • Agreement between two solvers with the same wrong model is not independent physical validation.
  • A formal covariance or Monte Carlo interval is conditional on the adopted model and noise process.

Lecture-specific derivation and assumptions

For a normalized floating-point number, write fl(x)=x(1+delta), with |delta| bounded approximately by unit roundoff u=2^-53 for binary64 elementary operations away from underflow/overflow. The spacing at 1 is 2^-52, so adding half that spacing lands on a tie; round-to-nearest, ties-to-even returns 1. Subtracting 1 then returns zero. If the increment is formed first, it remains representable. The subtraction has a large condition number because the exact result is tiny compared with the operands: algebraic equivalence does not imply numerical equivalence.

Algorithm trace and computed-output interpretation

Recreate both expression orders in float64 and print `np.spacing(1.0)`. Confirm that the first result is zero and the reordered result is half a spacing. Repeat with values near 2^k, where spacing scales as 2^(k-52), then perturb the input scale. The diagnostic addresses representation and conditioning only; it does not show that either expression encodes a scientifically accurate model.

Computed result: NumPy reports spacing 2.22045e-16 at 1.0; the half-spacing increment evaluates to 0 in the specified expression order.

The computed spacing is the smallest adjacent representable increment at unity, not a universal absolute accuracy. A result can be stable to floating-point perturbations and still be biased by rounded input data, omitted physics, or poor conditioning. Preserve extra precision only if the source information and downstream operations can use it.
