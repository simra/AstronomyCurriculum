# ASTR 474 Source

Use CPython 3.14.6 and the exact pins in `../requirements.txt`. From the repository root, create a clean environment with `py -3.14 -m venv .venv` and install the pins with `.venv/Scripts/python.exe -m pip install -r materials/ASTR474/requirements.txt` (POSIX: `.venv/bin/python -m pip install -r materials/ASTR474/requirements.txt`). Then run `.venv/Scripts/python.exe materials/ASTR474/src/generate_astr474_package.py --stage all` on Windows or `.venv/bin/python materials/ASTR474/src/generate_astr474_package.py --stage all` on POSIX. This command rebuilds the plan, numerical datasets, lecture/lab/problem-set artifacts, title-derived course index, SHA-256 manifest, and runs the package validator. To verify recorded file digests without rebuilding, run `.venv/Scripts/python.exe materials/ASTR474/src/validate_astr474_package.py --verify-checksums` (or the POSIX interpreter path). The validator recomputes shared numerical results and checks counts, local HTML links, lecture titles, unique lecture diagrams, and generated checksums.
