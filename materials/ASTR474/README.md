# ASTR 474: Computational Astrophysics

Three-credit Year 4 elective. Catalog description and prerequisites are listed in `syllabus.html`.

This package contains 14 lecture/notes pairs, 7 computational labs, 7 problem sets, instructor solutions, and assessment instructions. All displayed computed values are generated by `src/astr474_computations.py`; visual and instructional pages are regenerated with `src/build_astr474_materials.py`. See `reference-log.md` for source status and per-record provenance.

Release status is recorded in `course-manifest.json` and `review-report.md`. Review release does not constitute approval for instructional use; local policies and human spot-checks remain necessary.
