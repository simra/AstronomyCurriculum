# ASTR 430 Problem Set 04 Assessment Instructions

Inspect the submission, assignment, solution key, code/data, provenance record, and course policy.

## Standard
Award credit for correct method reconstruction, dimensional or decision consistency, explicit uncertainty, archive/software citation, and reproducibility. Separate arithmetic slips from conceptual errors. Check that level-3 records are not described as live observations.

## Revision
Give actionable feedback tied to a rubric criterion. Permit one resubmission with a change log while preserving high standards.
