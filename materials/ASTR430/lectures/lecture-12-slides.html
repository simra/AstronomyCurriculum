Why the method matters

Communication is part of reproducibility when the audience can identify evidence, uncertainty, and claim boundary.

Keep observation, calibration, transformation, model, and claim separate so each can be challenged.

Formal object

\(message=question+evidence+uncertainty+consequence\)

Define fields, units, defaults, version identifiers, and the boundary between measured, adopted, and inferred quantities.

Read the evidence

Identify which part is input, transformation, and claim. A caption should let a reader reproduce the path without asking the author what was omitted.

Worked audit

1-(1-0.05)^20 = 0.641514.

Estimate direction first, record units or decision criteria, then test one assumption. This check is generated from shared ASTR430 values.

Failure modes

  • A query without a release identifier is not a stable input.
  • A formal uncertainty does not include an unmodeled calibration offset.
  • A lower residual or p-value does not by itself validate a claim.

Active reasoning

Prompt: Compress a 12-panel analysis into a 90-second talk with one governing figure.

What would you record so a skeptical collaborator could rerun or challenge the conclusion?

Paired workshop

The workshop turns this method into a reproducible artifact: a query manifest, screening log, uncertainty table, figure critique, time budget, or proposal review. The deliverable includes result and provenance.

Takeaways

  • Build a concise narrative from question through evidence to limitation.
  • Every result needs an evidence chain and limitation statement.
  • Label live-verified documentation, standard literature, and instructor-provided records separately.
  • Make one hidden assumption visible in the paired assignment.
