Lecture 10: Survey Archives and Reproducible Queries

ASTR 210 Observational Astronomy and Data Reduction

Context and Why This Matters

Modern astronomy runs on public catalogs (Gaia, SDSS, and similar surveys), where the scientifically interesting sample is defined by the cuts applied to it, not simply by what the archive returns. Two astronomers using different, undocumented cuts on the same catalog can reach different conclusions from identical raw data.

Learning Goals

  1. Explain why a catalog query is a scientific decision, not a neutral data pull.
  2. Apply a parallax signal-to-noise cut and justify the threshold.
  3. Compute distances from parallax for a small archive sample.

Opening Phenomenon

A three-row archive excerpt reports parallaxes with very different fractional uncertainties. Naively inverting every parallax to get a distance produces one wildly unreliable value hiding among two good ones.

Vocabulary

  • parallax
  • fractional parallax error
  • selection function
  • query reproducibility
  • catalog flag
  • completeness
  • contamination

Evidence

  • Source 1: parallax = 5.1 mas, uncertainty = 0.2 mas (fractional error = 4%).
  • Source 2: parallax = 1.2 mas, uncertainty = 0.5 mas (fractional error = 42%).
  • Source 3: parallax = 8.8 mas, uncertainty = 0.1 mas (fractional error = 1%).

Model

  • A parallax measurement is only useful for a distance estimate when its fractional uncertainty is small (a common cut is requiring parallax/error > 5).
  • Distance in parsecs is the reciprocal of parallax in arcseconds; a poorly measured parallax produces a wildly uncertain, potentially unphysical, distance.
  • A reproducible query documents every cut applied (magnitude limits, parallax quality, flags) so another astronomer could recover the same sample.

Working Equation

\[ d\,({\rm pc}) = \dfrac{1}{\pi\,(\text{arcsec})} = \dfrac{1000}{\pi\,({\rm mas})} \]

Worked Example

  1. Source 1: parallax/error = 25.5 (passes a >5 cut); distance = 1000/5.1 = 196.1 pc.
  2. Source 2: parallax/error = 2.4 (fails a >5 cut); a naive distance of 833.3 pc should not be trusted and this source should be flagged or excluded.
  3. Source 3: parallax/error = 88.0 (passes easily); distance = 1000/8.8 = 113.6 pc.
  4. Applying a uniform parallax/error > 5 cut removes Source 2 from any distance-based analysis while keeping Sources 1 and 3 — exactly the kind of documented decision a reproducible query record must state explicitly.

Common Misconception

Reporting "the archive returned N objects" without stating the magnitude limits, quality flags, and parallax-quality cuts that produced that number — the sample cannot be reproduced or critiqued without them.

Active-Learning Guidance

Given two additional archive rows, decide which pass a parallax/error > 5 cut and compute distances only for those that do.
