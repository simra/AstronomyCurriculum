ASTR 210 · Lecture 10

Survey Archives and Reproducible Queries

The query record is part of the scientific result

Learning Goals

  1. Explain why a catalog query is a scientific decision, not a neutral data pull.
  2. Apply a parallax signal-to-noise cut and justify the threshold.
  3. Compute distances from parallax for a small archive sample.

Reading anchor: OpenStax Astronomy 2e, Chapter 19.2 (surveying the stars, parallax) and general survey-data practice.

Why This Matters

Modern astronomy runs on public catalogs (Gaia, SDSS, and similar surveys), where the scientifically interesting sample is defined by the cuts applied to it, not simply by what the archive returns. Two astronomers using different, undocumented cuts on the same catalog can reach different conclusions from identical raw data.

Opening Phenomenon

A three-row archive excerpt reports parallaxes with very different fractional uncertainties. Naively inverting every parallax to get a distance produces one wildly unreliable value hiding among two good ones.

First question: what here is directly measured, and what is inferred from a model?

Terms for This Lecture

parallax

Definition: The apparent annual angular displacement of a nearby source caused by observing from different positions in Earth’s orbit.

Why it matters here: It supplies a geometric distance indicator when the angular signal is measured with adequate precision.

Relationships: For parallax \(\pi\) in arcseconds, \(d(pc)=1/\pi\); the archive example uses milliarcseconds, so \(d=1000/\pi_{mas}\).

Boundary / common confusion: Naively inverting a low-SNR or negative measured parallax produces a biased or meaningless distance.

fractional parallax error

Definition: The ratio of parallax uncertainty to measured parallax, \(\sigma_\pi/\pi\).

Why it matters here: It provides a quick quality measure for deciding whether reciprocal distance is trustworthy.

Relationships: A parallax-to-error cut greater than five is equivalent to fractional error below 20 percent.

Boundary / common confusion: A threshold is a selection choice, not a correction for all distance biases.

selection function

Definition: The probability that an object with given properties enters the observed or queried sample.

Why it matters here: It explains how magnitude limits, quality cuts, sky coverage, and detection efficiency shape archive conclusions.

Relationships: Completeness and contamination are evaluated relative to the defined selection function.

Boundary / common confusion: A catalog subset is not automatically representative of the underlying population.

query reproducibility

Definition: The ability to rerun an archive request and recover the same sample from documented service, table, fields, filters, and query text.

Why it matters here: It makes the data-selection step inspectable in the same way as a reduction script.

Relationships: The query record is part of provenance and defines the sample before any physical model is fitted.

Boundary / common confusion: A screenshot or final row count is insufficient if the exact cuts and data release are absent.

catalog flag

Definition: A coded field describing data quality, processing status, duplication, saturation, or another condition attached to a catalog row.

Why it matters here: Flags let the analyst exclude or separately treat measurements known to violate assumptions.

Relationships: Flag filters contribute directly to the selection function and should be preserved in the query record.

Boundary / common confusion: A zero or “good” flag does not guarantee suitability for every scientific question.

completeness

Definition: The fraction of the target population satisfying the scientific definition that is actually included in the sample.

Why it matters here: It determines whether missing faint, crowded, or low-quality sources bias population inferences.

Relationships: Completeness is measured relative to source properties and the selection function, often using injection tests or deeper comparison data.

Boundary / common confusion: A large catalog can still be incomplete in precisely the regime most important to the analysis.

contamination

Definition: The fraction of selected objects that do not belong to the intended population or fail the intended quality standard.

Why it matters here: It measures the cost of permissive cuts and affects the credibility of trends inferred from the sample.

Relationships: Tightening cuts often lowers contamination while also reducing completeness, creating a documented tradeoff.

Boundary / common confusion: Contamination is not identical to random measurement error; it concerns unwanted sample membership.

Evidence We Need to Explain

  • Source 1: parallax = 5.1 mas, uncertainty = 0.2 mas (fractional error = 4%).
  • Source 2: parallax = 1.2 mas, uncertainty = 0.5 mas (fractional error = 42%).
  • Source 3: parallax = 8.8 mas, uncertainty = 0.1 mas (fractional error = 1%).

Model

  • A parallax measurement is only useful for a distance estimate when its fractional uncertainty is small (a common cut is requiring parallax/error > 5).
  • Distance in parsecs is the reciprocal of parallax in arcseconds; a poorly measured parallax produces a wildly uncertain, potentially unphysical, distance.
  • A reproducible query documents every cut applied (magnitude limits, parallax quality, flags) so another astronomer could recover the same sample.

Quantitative Tool

\[ d\,({\rm pc}) = \dfrac{1}{\pi\,(\text{arcsec})} = \dfrac{1000}{\pi\,({\rm mas})} \]

Worked Example

  1. Source 1: parallax/error = 25.5 (passes a >5 cut); distance = 1000/5.1 = 196.1 pc.
  2. Source 2: parallax/error = 2.4 (fails a >5 cut); a naive distance of 833.3 pc should not be trusted and this source should be flagged or excluded.
  3. Source 3: parallax/error = 88.0 (passes easily); distance = 1000/8.8 = 113.6 pc.
  4. Applying a uniform parallax/error > 5 cut removes Source 2 from any distance-based analysis while keeping Sources 1 and 3 — exactly the kind of documented decision a reproducible query record must state explicitly.

Visual Reasoning

Use the quality-cut line to judge each archive source.

  • Why does Source 2 fail the cut despite having a measured parallax?
  • What happens to the inferred distance if you ignore the cut and invert Source 2’s parallax anyway?

Common Pitfall

Reporting "the archive returned N objects" without stating the magnitude limits, quality flags, and parallax-quality cuts that produced that number — the sample cannot be reproduced or critiqued without them.

Active Learning Segment

Given two additional archive rows, decide which pass a parallax/error > 5 cut and compute distances only for those that do.

Lab or Observing Connection

Lab 07 (Archive Query Reproducibility) requires writing out the exact cuts applied to a larger sample and reporting how many sources each cut removes.

Synthesis

Archive science requires the query record to be as carefully documented as the scientific interpretation that follows it.
