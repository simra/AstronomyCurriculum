ASTR 210 · Lecture 05

Aperture Photometry

Measurement design as much as calculation

Learning Goals

  1. Define instrumental magnitude and photometric zero point.
  2. Derive a zero point from one standard star and verify it against two others.
  3. Explain how aperture and sky-annulus choice bias a photometric measurement.

Reading anchor: OpenStax Astronomy 2e, Chapter 17.1 (the brightness of stars, magnitudes).

Why This Matters

Aperture photometry converts pixel counts into a calibrated brightness, but the same star can yield different reported magnitudes depending on aperture radius, sky-annulus placement, and how carefully the zero point was derived. Photometry is a measurement-design problem, not only an arithmetic one.

Opening Phenomenon

A photometric pipeline processes three standard stars in the same field and filter. If the zero point derived from one star is correct, it should reproduce the catalog magnitudes of the other two without further adjustment.

First question: what here is directly measured, and what is inferred from a model?

Vocabulary for Reasoning

Use these terms to describe evidence and relationships, not as isolated definitions.

Evidence We Need to Explain

  • STD-A: 150000 counts in a 30 s exposure, catalog V = 10.21.
  • STD-B: 62000 counts in 30 s, catalog V = 11.17.
  • STD-C: 24000 counts in 30 s, catalog V = 12.2.

Model

  • Instrumental magnitude is defined from a count rate (counts per second), not raw counts, so exposures of different length can be compared.
  • The zero point ZP absorbs the telescope aperture, filter throughput, and detector sensitivity into one number for a given night and setup.
  • A zero point derived from a single well-measured standard should reproduce the catalog magnitudes of independent standards if the calibration is internally consistent.

Quantitative Tool

\[ m = -2.5\log_{10}(\text{rate}) + {\rm ZP} \]

Worked Example

  1. STD-A count rate = 150000/30 = 5000.0 counts/s.
  2. Solve for the zero point using the catalog magnitude: ZP = 10.21 + 2.5×log10(5000.0) = 10.21 + 9.247 = 19.457.
  3. Apply ZP to STD-B: rate = 2066.7 counts/s, predicted m = −2.5×log10(2066.7) + 19.457 = 11.169 (catalog: 11.17) — agreement to about 1 millimagnitudes.
  4. Apply ZP to STD-C: rate = 800.0 counts/s, predicted m = −2.5×log10(800.0) + 19.457 = 12.200 (catalog: 12.2) — agreement to about 0 millimagnitudes.
  5. Because both independent checks reproduce the catalog values to a few millimagnitudes, this zero point is internally consistent and can be applied to the unknown target in the same field.

Visual Reasoning

Use the aperture/annulus schematic and the zero-point check together.

  • Why must the sky annulus be placed outside the source aperture?
  • What would it mean if STD-B or STD-C fell far off the 1:1 line?

Common Pitfall

Choosing an aperture radius too small (losing source flux to the wings of the point-spread function) or too large (including excess sky noise), then blaming the resulting magnitude error on "bad seeing" rather than measurement design.

Synthesis
