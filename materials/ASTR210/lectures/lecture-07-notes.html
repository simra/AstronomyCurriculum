Lecture 07: Astrometry and Plate Solutions

ASTR 210 Observational Astronomy and Data Reduction

Context and Why This Matters

Pixels become right ascension and declination only after an image is matched to a reference catalog through a plate solution (World Coordinate System). Astrometry underlies proper motions, orbit determination for asteroids and comets, and the reference frames used for every other kind of positional measurement.

Learning Goals

  1. Explain how a plate solution links pixel coordinates to sky coordinates.
  2. Derive a plate scale from two matched image/catalog coordinate pairs.
  3. State what residual analysis after a plate solution tells you about systematic error.

Opening Phenomenon

An asteroid imaged twice, minutes apart, shifts noticeably in pixel coordinates. Converting that pixel shift into an angular sky motion requires knowing the plate scale (arcseconds per pixel), which is itself derived from the same data.

Vocabulary

  • centroid
  • plate scale
  • World Coordinate System (WCS)
  • astrometric residual
  • proper motion
  • reference catalog
  • pixel-to-sky transformation

Evidence

  • Image 1: (x, y) = (520.3, 411.2) px corresponds to (RA, Dec) = (132.1021°, 12.5510°).
  • Image 2, taken shortly after: (x, y) = (534.7, 415.8) px corresponds to (RA, Dec) = (132.0988°, 12.5521°).
  • The pixel shift and the sky-coordinate shift both scale together, which is exactly the relationship a plate solution is built to capture.

Model

  • A plate solution is a geometric transformation, calibrated using catalog stars, from pixel coordinates to sky coordinates.
  • Plate scale (arcsec/pixel) converts a measured pixel displacement into a physically meaningful angular displacement.
  • A believable astrometric position always comes with a residual: the leftover scatter between predicted and catalog positions of the calibration stars.

Working Equation

\[ \text{plate scale} = \dfrac{\Delta(\text{sky separation, arcsec})}{\Delta(\text{pixel separation, px})} \]

Worked Example

  1. Pixel displacement: Δx = 14.4 px, Δy = 4.6 px, so the total pixel separation is √(14.4² + 4.6²) = 15.12 px.
  2. Sky displacement: ΔRA·cos(Dec) = 11.596 arcsec, ΔDec = 3.960 arcsec, so the total angular separation is 12.25 arcsec.
  3. Plate scale = 12.25 arcsec / 15.12 px = 0.811 arcsec/pixel.
  4. This plate scale, once derived, can be applied to any other pixel measurement on the same image without re-deriving it from scratch — but only if the optical setup has not changed.

Common Misconception

Treating a measured centroid as the final position without asking about the plate-solution residual. A centroid can be very precise (small statistical uncertainty) yet still biased by an uncorrected optical distortion.

Active-Learning Guidance

Given a third image/catalog coordinate pair, check whether it predicts the same plate scale derived above to within about 5%, and discuss what a large discrepancy would imply.
