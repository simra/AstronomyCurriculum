# ASTR 340 Datasets

- `telescopes.csv` - Real telescope apertures and effective focal lengths (Keck, HST, VLT, JWST, Gemini North, and a representative amateur reflector). Keck's aperture and focal length are live-verified this session (see `../reference-log.md`); the others are standard published mission/facility specifications.
- `hires_echelle.csv` - Keck HIRES echelle spectrograph parameters: radial-velocity precision and 1 AU planet-detection limit (live-verified this session), plus resolving power, groove density, and blaze angle (standard published instrument specifications).
- `ccd_qe_curve.csv` - Representative published quantum-efficiency curve for an e2v CCD231-84-class scientific CCD, wavelength versus QE percent.
- `ubvri_filters.csv` - Johnson-Cousins UBVRI photometric system central wavelengths and effective bandwidths (Bessell 1990, standard published values).

Generated by `../src/generate_astr340_content.py`. Do not hand-edit; regenerate from the source script if any underlying constant changes.
