# ASTR 476 Data

`pantheonplus-subset.csv` is an 18-object, redshift-stratified subset extracted from the live-verified Pantheon+SH0ES public table. `pantheonplus-subset-covariance.csv` is the matching 18x18 block from the official 1701x1701 statistical-plus-systematic covariance. Selection, row alignment, hashes, access date, and the non-representative-use warning are in `pantheonplus-subset-provenance.json`. This subset is not a survey likelihood and cannot reproduce published cosmological constraints. The diagonal error column is for plotting only.

`published-summary-measurements.csv` contains level-2 published summaries, not raw data vectors. `computed-reference-results.json` and `pantheonplus-gls-intercept.json` are reproducible model/derived outputs. Consult `../reference-log.md` for per-source provenance and limitations.
