Lab 07: Cross-probe evidence dossier

ASTR 476: Observational Cosmology · 2026-09-25

Scope: Lectures 13-14 · Purpose: Produce an auditable mini-analysis that traces a quantitative claim through provenance, calibration, covariance, model, and independent check.

Setup and data

  • Use the published summary CSV and Pantheon+ subset with its matched covariance.
  • No joint Planck/BOSS/DES/Pantheon+ posterior is supplied or implied.
  • Choose one claim whose strength is supported by the available subset or summary, then state what it cannot establish.

Procedure

  1. Select one measured or published-summary quantity and write the exact source/model label.
  2. Recompute one derived number from source fields with a short script and test.
  3. Record data digest, code version, units, covariance use, and all transformations.
  4. Compare with an independent implementation or limiting case.
  5. Write a claim/evidence/limitation table and perform a peer red-team review.
  6. Archive a clean run command and environment lock file.

Deliverables

Deliver: a one-page evidence dossier, source/data digest, executable analysis, test output, and peer review response.

Assessment criteria

Rubric: provenance/chain 25%; numerical reproducibility 25%; correct evidence claim 20%; limitations 15%; reviewability 15%.

Uncertainty and interpretation

Report numerical precision, input uncertainty, model assumptions, and covariance availability separately. Label every output as directly measured, published summary, derived, or model/synthetic. A successful script run is not evidence that the scientific interpretation is valid.

Revisions and resubmissions are encouraged. Credit is based on defensible reasoning, validation, provenance, and clear limitations.
