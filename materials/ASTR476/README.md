# ASTR 476: Observational Cosmology

This package contains 14 lecture/notes pairs, seven paired-module labs, seven problem sets with solutions and grading instructions, source-tagged data, and reproducible calculations. The Pantheon+ teaching excerpt is real, covariance-aligned, and deliberately limited; see `reference-log.md`.

Use CPython 3.14.6. Install `requirements.txt`, then from the repository root run `python materials/ASTR476/src/prepare_pantheon_excerpt.py` once to refresh the official excerpt, followed by `python materials/ASTR476/src/build_astr476_package.py`. Generated numerical answers and SVG diagrams are rebuilt from source. The package validator is `src/validate_astr476_package.py`.
