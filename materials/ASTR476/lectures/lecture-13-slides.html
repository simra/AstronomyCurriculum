Interpretation and limits

Precision cosmology depends on calibration chains and nuisance models as much as sample size. An error budget names sources, correlations, mitigation, and residual validation rather than collapsing every uncertainty into one bar.

Boundary: A checksum proves file identity, not scientific validity; provenance, versioning, units, and independent checks are also required.

Evidence: The package makes distinct records for live-verified Pantheon+ source data, published summary values not re-fetched from the paper, and theoretical or synthetic illustrations.

Active check: Record source URL, retrieval date, source digest, transform, code version, and caveat for every data product.
