ASTR 350 Problem Set 04: Atmospheres and Escape

Extend this unit's scale-height and Jeans-escape reasoning.

Problems

1. Scale height and gravity 15 points

Using this unit's reading, explain quantitatively (using the scale-height formula) why a planet with the same temperature but twice HD 209458 b's surface gravity would have a transmission-spectroscopy signal only half as large, all else equal.

2. Jeans parameter for a rocky planet 15 points

Compute the Jeans escape parameter for Earth-mass hydrogen atoms at Earth's exobase (assume T≈1000 K, use Earth's real mass and radius from materials/ASTR350/data/), and compare it to HD 209458 b's value (10.93). State which planet is in more danger of hydrodynamic hydrogen escape and why this is consistent with Earth having retained only trace atmospheric hydrogen today.

3. Mass-loss timescale sensitivity 15 points

If HD 209458 b's real mass-loss rate had instead been measured as 9.0e+08 kg/s (three times the real value), recompute the naive mass-loss timescale and state whether this would change the conclusion about the planet's long-term survival at the currently observed rate.

4. Escape and the radius valley 15 points

Connect this unit's escape-parameter reasoning explicitly to Lecture 04's radius-valley discussion: explain why a lower-mass sub-Neptune at HD 209458 b's orbital distance would have a smaller Jeans parameter (all else equal) and therefore be more vulnerable to complete envelope loss than HD 209458 b itself.

Due and Scope

Submit a complete derivation with equations, units, labeled quantities, and a short narrative interpretation for each problem. Show every step; a correct final number without a visible derivation receives partial credit at most, and quoting a lecture number without adapting it to this problem's specific inputs receives no credit for that step.
