# ASTR 230 Data

Datasets used by `src/generate_astr230_content.py` and `src/generate_astr230_labs_psets.py`. All values are also embedded directly in the generator scripts as the single source of truth; these CSV files are exported copies for student/lab use.

- `nearby_bright_stars.csv` - 20-star sample (Sun plus 19 well-known nearby/bright stars) with apparent magnitude, parallax, spectral type, approximate effective temperature and luminosity, used in Lecture 01-03, Lab 01, Lab 02, PS 01, PS 02.
- `milky_way_rotation_curve.csv` - representative Milky Way circular-velocity curve, used in Lecture 10, Lab 05, PS 05.
- `hubble_diagram_clusters.csv` - five-cluster redshift-distance sample, used in Lecture 14, Lab 07, PS 07.

See `reference-log.md` for provenance and human spot-check requirements.
