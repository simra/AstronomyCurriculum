ASTR 470 Lab 04: Pulsar timing and braking

Lectures 05-06 · high-energy data activity

Objectives

  • calculate characteristic age, dipole field, and rotational energy loss from timing records
  • Separate event counts or catalog values from calibrated and inferred quantities.
  • Quantify one uncertainty, sensitivity, or selection effect.
  • Produce a reproducible figure/table with a scientific caption.

Materials and setup

Use Python 3, the supplied pulsar_timing.csv, and the source documentation named below. The supplied record is clearly labeled in data/README.md. Record file hash, row count, columns, units, processing state, and provenance level.

Computed check: R < 1154.3 AU The bound assumes the observed variability is intrinsic and that the Doppler factor is known.

Procedure

  1. Inspect the file and make a schema table before filtering or fitting.
  2. Reproduce the baseline calculation with units and an independent hand-derived formula.
  3. Apply the activity-specific task: calculate characteristic age, dipole field, and rotational energy loss from timing records.
  4. Perform one perturbation or alternative-model test and report the direction of change.
  5. Write a caption that identifies data, transformation, inference, uncertainty, and limitation.
