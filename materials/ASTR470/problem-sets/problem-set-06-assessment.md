# ASTR 470 Problem Set 06 Assessment Instructions

Inspect the student submission, assignment, solution key, code/data, provenance record, and course policy.

## Standard
Award credit for a correct physical model, dimensional consistency, explicit assumptions, uncertainty or sensitivity treatment, evidence-grounded interpretation, and reproducibility. Check the comparative direction and every large unit conversion. Distinguish observed counts, calibrated products, inferred parameters, and model claims.

## Feedback and revision
Separate arithmetic slips from conceptual errors, unsupported mission claims, missing provenance, and communication defects. Give actionable feedback tied to the 30/30/20/20 rubric. Permit one resubmission with a change log; preserve the high standard for reasoning and evidence.
