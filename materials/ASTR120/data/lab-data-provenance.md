# ASTR 120 Lab Data Provenance

Created for review release on 2026-09-23. These compact CSV files are teaching datasets assembled from named public NASA/OpenStax sources so students can complete calculations without relying on hidden instructor files. They are not archival mission products.

- `lab-01-planetary-properties.csv`: selected values from NASA Planetary Fact Sheet tables; rounded to classroom precision.
- `lab-02-orbital-resonances.csv`: satellite orbital periods and semimajor axes from NASA planetary satellite fact sheets; rounded to listed significant figures.
- `lab-03-crater-counts.csv`: instructor-count teaching table from named real mosaics, using LROC WAC lunar and Mars Odyssey THEMIS image products as provenance anchors. Counts are processed classroom measurements, not a published crater chronology catalog.
- `lab-04-atmospheres-climate.csv`: planetary atmosphere and bulk-property values from NASA Planetary Fact Sheet tables.
- `lab-05-mars-water-evidence.csv`: curated teaching table from NASA mission science summaries for Mars 2020, MER Opportunity, MRO CRISM/HiRISE, and MSL Curiosity.
- `lab-06-icy-moon-habitability.csv`: curated comparative table from NASA Europa Clipper, Cassini, Cassini-Huygens, and Solar System Exploration science pages.
- `lab-07-mission-trade-matrix.csv`: instructor-created trade-study matrix using public NASA mission/program pages as precedent and provenance. Scores are pedagogical estimates for decision-matrix practice.

Suggested citation in student work: ASTR 120 teaching dataset, assembled from NASA/OpenStax sources listed in `materials/ASTR120/reference-log.md`, accessed for course package review on 2026-09-23.
