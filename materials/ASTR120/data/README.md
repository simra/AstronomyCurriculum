# ASTR 120 Data

This folder contains compact teaching datasets for ASTR 120 lab activities. Files are intentionally small enough for spreadsheet work and include provenance in each lab plus `lab-data-provenance.md`.

| File | Used by | Processing state |
|---|---|---|
| `lab-01-planetary-properties.csv` | Lab 01: Planetary Scale, Density, and Architecture | Real NASA Planetary Fact Sheet values, rounded for instruction. |
| `lab-02-orbital-resonances.csv` | Lab 02: Orbital Resonances and Period Ratios | Real NASA satellite fact-sheet values, selected and rounded for instruction. |
| `lab-03-crater-counts.csv` | Lab 03: Crater Counting and Relative Surface Age | Instructor-count teaching table from named real LROC WAC and Mars Odyssey THEMIS mosaics. |
| `lab-04-atmospheres-climate.csv` | Lab 04: Atmospheres, Escape, and Climate | Real NASA planetary and satellite fact-sheet values, selected and rounded for instruction. |
| `lab-05-mars-water-evidence.csv` | Lab 05: Mars Water Evidence | Curated teaching table from NASA Mars mission science summaries. |
| `lab-06-icy-moon-habitability.csv` | Lab 06: Icy Moon Habitability | Curated comparative table from NASA mission and Solar System Exploration pages. |
| `lab-07-mission-trade-matrix.csv` | Lab 07: Mission Design Trade Study | Instructor-created decision matrix using public NASA mission precedents and pedagogical risk scores. |
