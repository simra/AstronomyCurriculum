# Assessment Instructions: ASTR 120 Problem Set 02

## Inputs to Inspect

- Student submission for Problem Set 02.
- Student problem set: `materials/ASTR120/problem-sets/problem-set-02.html`.
- Instructor solution key: `materials/ASTR120/problem-sets/problem-set-02-solutions.html`.
- Course syllabus and grading policy: `materials/ASTR120/syllabus.html`.
- Lecture artifacts for Lectures 03-04.

## Grading Standard

Assess orbital calculations, units, physical interpretation, and evidence weighting. Full credit requires equations, numerical work, assumptions, and a conclusion that does not overclaim what the data prove.

## Problem-Level Criteria

- Problem 1: distinguish semimajor-axis inputs from period ratios and correctly identify 2:1 and 3:1 resonances.
- Problem 2: apply \(e^2\) scaling, keep W units, and explain resonance-maintained eccentricity.
- Problem 3: compute density ratios with cubed radius terms and interpret core fraction cautiously.
- Problem 4: connect each evidence type to an interior constraint and give plausible alternatives.

## Feedback Requirements

Identify conceptual mistakes separately from arithmetic slips. Point students to the exact missing step: equation setup, unit conversion, ratio interpretation, evidence weighting, or communication clarity.

## Integrity and Evidence Checks

Flag untraceable tables, copied text, fabricated spacecraft evidence, and outside data without citation. Check that any spreadsheet or code output reproduces the submitted values.

## Resubmission Pathway

Students may revise with a change note. Feedback should guide the repair while preserving the need for students to redo calculations and reasoning themselves.
