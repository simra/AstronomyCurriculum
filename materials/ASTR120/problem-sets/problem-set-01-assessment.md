# Assessment Instructions: ASTR 120 Problem Set 01

## Inputs to Inspect

- Student submission for Problem Set 01.
- Student-facing assignment: `materials/ASTR120/problem-sets/problem-set-01.html`.
- Instructor solution key and rubric: `materials/ASTR120/problem-sets/problem-set-01-solutions.html`.
- Course syllabus and grading policy: `materials/ASTR120/syllabus.html`.
- Lecture artifacts: `materials/ASTR120/lectures/lecture-01-notes.html`, `lecture-01-slides.html`, `lecture-02-notes.html`, and `lecture-02-slides.html`.

## Grading Standard

Grade to a high first-year undergraduate standard with explicit attention to units, assumptions, evidence quality, and interpretation. Award full credit only when numerical work is dimensionally consistent, reasoning is tied to the lecture evidence chain, and limitations are specific rather than generic.

## Problem-Level Criteria

- Problem 1: verify scaled distances, one correctly scaled diameter, and defensible evidence tags. Treat a wrong scale conversion as mathematical; treating inferred composition as directly observed is conceptual.
- Problem 2: require the volume formula, km-to-m conversion, density in both unit systems, ratio check, and a restrained interpretation. Small arithmetic slips can receive partial credit if the method and units are sound.
- Problem 3: require algebraic rearrangement of the temperature law, both condensation radii, classifications of all four worlds, and one physically plausible limitation.
- Problem 4: require a falsifiable prediction, a three-row evidence table, and a conclusion that distinguishes support, ambiguity, and model limits.

## Feedback Requirements

For each problem, report the score, what is correct, what is missing, and the most important revision. Identify whether each issue is conceptual, mathematical, arithmetic, evidence-based, or communication-related. Do not give full credit for unsupported final numbers, missing units, or unqualified claims that a model is proven.

## Integrity and Evidence Checks

Flag copied prose, fabricated citations, outside values used without citation, and tables or calculations that cannot be traced to the submitted work. If a student uses outside planetary data, require a credible source and note whether it changes the conclusion.

## Resubmission Pathway

Students may revise and resubmit with a change note. Feedback should point to the flawed reasoning step or missing evidence category without simply rewriting the full solution unless the solution key has already been released.
