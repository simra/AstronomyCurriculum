# Assessment Instructions: ASTR 120 Problem Set 06

## Inputs to Inspect

- Student submission for Problem Set 06.
- Student problem set: `materials/ASTR120/problem-sets/problem-set-06.html`.
- Instructor solution key: `materials/ASTR120/problem-sets/problem-set-06-solutions.html`.
- Course syllabus and grading policy: `materials/ASTR120/syllabus.html`.
- Lecture artifacts for Lectures 11-12.

## Grading Standard

Assess impact calculations, comet-orbit reasoning, transit-depth inference, detection bias, units, and evidence-based comparison. Full credit requires reproducible calculations and clear physical interpretation.

## Problem-Level Criteria

- Problem 1: spherical mass, SI kinetic energy, megaton conversion, and \(v^2\) scaling.
- Problem 2: semimajor axis, Kepler period, sublimation-driven activity, and comet/asteroid ambiguity.
- Problem 3: squared radius ratio, ppm conversion, precision comparison, and transit biases.
- Problem 4: day-to-year conversion, semimajor axes, solar-system comparison, discovery bias, and migration/formation hypothesis.

## Feedback Requirements

Separate arithmetic slips from conceptual errors such as using diameter as radius, not squaring transit radius ratio, or treating observed exoplanet samples as unbiased.

## Integrity and Evidence Checks

Flag fabricated exoplanet sources, copied web text, unlabeled plots, untraceable spreadsheets, and outside values without citation.

## Resubmission Pathway

Students may revise with a change note. Require corrected calculations and a new explanation of the physical meaning, not just changed final numbers.
