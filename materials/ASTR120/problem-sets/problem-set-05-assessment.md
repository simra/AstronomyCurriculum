# Assessment Instructions: ASTR 120 Problem Set 05

## Inputs to Inspect

- Student submission for Problem Set 05.
- Student problem set: `materials/ASTR120/problem-sets/problem-set-05.html`.
- Instructor solution key: `materials/ASTR120/problem-sets/problem-set-05-solutions.html`.
- Course syllabus and grading policy: `materials/ASTR120/syllabus.html`.
- Lecture artifacts for Lectures 09-10.

## Grading Standard

Assess calculations, comparison logic, indirect evidence, units, and physical interpretation. Full credit requires recognizing uncertainty in icy-ocean evidence and avoiding rigid-ring misconceptions.

## Problem-Level Criteria

- Problem 1: giant-planet density calculations, Saturn less-than-water identification, and composition interpretation.
- Problem 2: inverse-square sunlight table and internal-heat interpretation.
- Problem 3: measurement-to-ocean evidence chain, ambiguities, ranking, and tidal-heating logic.
- Problem 4: ring-period ratio, outer period estimate, shear, and confinement/replenishment reasoning.

## Feedback Requirements

Separate arithmetic from conceptual errors. Note whether weak answers lack units, confuse mass with density, overstate ocean evidence, or treat rings as solid structures.

## Integrity and Evidence Checks

Flag unsupported mission claims, copied web summaries, untraceable calculations, and outside numbers without citation.

## Resubmission Pathway

Students may revise with a change note. Feedback should identify the evidence or calculation that must be repaired without giving away unreleased solution text.
