# ASTR 320 Datasets

This course keeps its real-world constants (solar-system planet parameters, TRAPPIST-1 system, moon/ring data, moment-of-inertia factors, magnetic-field values) embedded directly as Python constants in `../src/generate_astr320_content.py` and `../src/generate_astr320_labs_psets.py`, rather than exported to CSV files. See `../reference-log.md` for the full per-dataset source and verification-level (live-verified / standard published / synthetic) table.

Regenerate lectures/labs/problem sets from the source scripts if any underlying constant changes; do not hand-edit the generated HTML.
