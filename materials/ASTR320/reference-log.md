# ASTR 320 Reference Log

Tracks references, datasets, and visuals used in ASTR 320 materials, their verification status, and any human spot-check requirements. Provenance is labeled at one of three explicit levels throughout: **(1) live-verified this session** (fetched/extracted from a primary or authoritative source during this course's production), **(2) standard published/literature value not re-verified this session** (flagged for human spot-check), or **(3) synthetic/instructor-provided placeholder**. No purely synthetic (non-literature) numeric data is used anywhere in this package; every real-world number is either level 1 or level 2.

## Textbook

- OpenStax Astronomy 2e (openly licensed; local extracted copy `references/openstax-astronomy-2e-extracted.txt`; problem index `references/source-indexes/openstax-astronomy-2e-problem-index.md`). Chapter numbers cited in ASTR 320 materials use the **published edition's native chapter numbering**, following the ASTR 230/310 precedent for resolving the source index's internal &minus;1 chapter-numbering offset. Status: chapter alignment inferred by extrapolation from adjacent verified ASTR 310 citations (Chapters 7, 9&ndash;13), not independently re-cross-checked against embedded figure/table numbering this session &mdash; flagged for human spot-check. Several ASTR 320 topics (the radiative-equilibrium disk-temperature/frost-line derivation, the moment-of-inertia interior-structure formalism, the hydrostatic scale-height and Jeans-escape derivations, the magnetopause pressure-balance derivation, and the Roche-limit and tidal-heating derivations) are **not covered at the introductory level in OpenStax Astronomy 2e at all** and are developed here from first principles instead; this is stated explicitly in `syllabus.html`, `schedule.html`, and each affected lecture's slides/notes rather than presented as an OpenStax-sourced result.

## Corrections Made During Review

- **Escape-velocity comparative statement (Lecture 01):** the original draft hand-typed "4.25 km/s (Mercury) to 59.5 km/s (Jupiter)" in a bullet, which did not match this course's own computed Jupiter escape velocity (60.2 km/s, using the same `G_NEWTON`/mass/radius values as the deck's own worked-example table). Replaced the hardcoded string with a computed f-string drawing directly from the same `ESCAPE_VS` values used in the worked example, so the bullet and the table can never drift apart again.
- **Tidal-acceleration ranking (Lecture 13):** the original draft claimed "all three fractions are small (well under 1%)" and that "Io's fraction... is the largest of the three... correctly ranks Io as experiencing the strongest relative tidal stress." Independent recomputation showed Enceladus's tidal-acceleration fraction (1.25% of its own surface gravity) is actually larger than Io's (0.34%), because Enceladus's own surface gravity is so weak that even its smaller absolute tidal acceleration is a larger fraction of it. Corrected the text to state the true ranking, and to explicitly distinguish "largest fractional tidal stress relative to a moon's own weak gravity" (Enceladus) from "most tidally heated in absolute, geologically observable terms" (Io, still true and still the largest absolute tidal acceleration/heating power of the three) rather than conflating the two rankings.
- **Missing reading/scope note (Lecture 05):** unlike every other lecture, Lecture 05 (Plate Tectonics and Comparative Surface Geology) had no "Reading and Scope Note" section citing an OpenStax chapter/section, breaking the course's otherwise consistent per-lecture citation pattern. Added a reading note citing OpenStax Astronomy 2e Section 9.3&ndash;9.4, consistent with the section numbering already used for the adjacent Lectures 03, 04, and 06 (9.1, 9.1&ndash;9.2, and 9.5&ndash;9.6 respectively).
