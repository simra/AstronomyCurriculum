Problem Set 01: Solution Key

Equation of State and Opacity for Alpha Centauri B

Worked Solutions

1. Central pressure

M = 1.8084e+30 kg, R = 6.0108e+08 m. P_c = (3/8π)GM²/R⁴ = 1.996e+14 Pa.

2. Comparison to the Sun

Alpha Centauri B's estimated central pressure (1.996e+14 Pa) is 1.483 times the Sun's (1.345e+14 Pa) -- lower, consistent with both its smaller mass (reducing M² in the numerator) and smaller radius (reducing R⁴ in the denominator, which would raise P_c) combining so that the mass effect dominates for these specific values.

Correct computed ratio8
Correct qualitative M vs. R⁴ scaling argument7

3. Electron-scattering opacity

κ_es = σ_T(1+X)/(2m_p) = 0.0338 m²/kg. This value depends only on composition (X) and fundamental constants, not on any star-specific density or temperature, so it is identical for every fully ionized star of the same hydrogen mass fraction.

Correct arithmetic8
Correct composition-only dependence explanation7

4. Radiation-to-gas pressure ratio

Because P_rad/P_gas ∝ T³/ρ and Alpha Centauri B has a lower core temperature than the Sun (and a comparable or somewhat higher core density, given its smaller radius at similar mass), the ratio is expected to be smaller than the Sun's already-negligible value -- radiation pressure is even less important in Alpha Centauri B's core than in the Sun's.
