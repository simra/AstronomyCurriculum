Problem Set 02: Solution Key

Radiative Gradient and the Schwarzschild Criterion for Sirius A’s Envelope

Worked Solutions

1. Radiative gradient

∇_rad = 3κLP/(16πacGMT⁴) = 4.1045e-03, using κ = 0.0338 m²/kg, L = 9.723e+27 W, P = 1.0 × 10¹² Pa, M = 3.898e+30 kg, T = 3.0 × 10⁶ K.

2. Schwarzschild classification

∇_rad (4.1045e-03) is far greater than ∇_ad (0.4), so this illustrative envelope point is convectively unstable in this model.

3. Comparison to the Sun

Since ∇_rad ∝ L directly, and Sirius A is about 25 times more luminous than the Sun, a proportionally larger ∇_rad is expected for otherwise similar opacity, pressure, mass, and temperature conditions -- consistent with the much larger value found in Problem 1 relative to the Sun's 0.0982.

4. Physical interpretation

This problem set's single illustrative envelope point, using electron-scattering opacity only, finds convective instability there, which is not the same as real A-type stars' radiative envelopes; real A-type stellar envelopes have lower opacity and different pressure/temperature structure than this simplified illustrative point assumes. Correctly classifying Sirius A's actual envelope and core would require a full, depth-resolved stellar model with a realistic opacity table, not a single schematic sample point.
