# ASTR 410 Data

The CSV files are compact teaching extracts: rotation-curve points, population abundance summaries, and nearby-galaxy kinematics. Values are standard published/literature or survey-summary values not independently re-queried in this production session (provenance level 2), and require human spot-checking against the named sources in `../reference-log.md`. They are not new measurements. The files are intentionally small enough for reproducible undergraduate analysis; students must record row counts, units, and any selection cuts.
