# ASTR 101 Problem Sets

Problem sets, solution keys, and assessment instructions have been generated here for review. The current files are second-pass drafts with concrete lecture-specific problems, worked solution keys, assessment instructions, and recommended OpenStax practice references.

Naming convention:

- `problem-set-01.html`
- `problem-set-01-solutions.html`
- `problem-set-01-assessment.md`

Student-facing problem sets are separate from instructor solution keys. Assessment instructions support high grading standards and resubmission for improved mastery.
