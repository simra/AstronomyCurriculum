# ASTR 101: Introduction to Astronomy with Observing Lab

Status: approved for review release; not yet approved for instructional use.

This folder contains the course-specific materials for ASTR 101. The package follows the repository convention that every course lives under `materials/<COURSECODE>/`, with course-specific source code in `src/` and datasets in `data/`.

## Course Identity

- Course number: ASTR 101
- Title: Introduction to Astronomy with Observing Lab
- Credits: 4
- Prerequisites: None
- Program placement: Year 1, Fall

## Current Artifacts

- `syllabus.html` - full course syllabus, learning outcomes, assessments, resubmission policy, and resources.
- `schedule.html` - authoritative 14-week lecture and observing/lab schedule.
- `course-manifest.json` - artifact plan, dependency order, statuses, and naming conventions.
- `reference-log.md` - source, data, and visual verification log.
- `lectures/`, `labs/`, `problem-sets/` - generated review-release artifacts for lectures, labs, problem sets, solution keys, and assessment instructions.
- `src/` - course-specific scripts, notebooks, plotting tools, and validation code.
- `data/` - course-specific raw, processed, or synthetic datasets with provenance notes.

## Naming Convention

Use two-digit numbering:

- `lectures/lecture-01-slides.html`
- `lectures/lecture-01-notes.html`
- `labs/lab-01.html`
- `problem-sets/problem-set-01.html`
- `problem-sets/problem-set-01-solutions.html`
- `problem-sets/problem-set-01-assessment.md`
