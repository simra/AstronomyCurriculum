# ASTR 310: Astrophysics I: Radiation, Matter, and Orbits

4-credit, 300-level, one-semester course. Year 3, Fall, in the four-year curriculum. Prerequisites: ASTR 230; MATH 251; PHYS 172.

See [syllabus.html](syllabus.html) for the full syllabus, [schedule.html](schedule.html) for the lecture/lab/problem-set schedule, and [index.html](index.html) for the full course package landing page.

## Structure

- `lectures/` - 14 lecture slide decks and paired lecture notes.
- `labs/` - 7 labs (biweekly, matched 1:1 with problem sets).
- `problem-sets/` - 7 problem sets, each with a solution key and assessment instructions.
- `src/` - generator scripts that compute every worked example programmatically and produce the HTML lecture/lab/problem-set content.
- `data/` - course datasets (see `data/README.md`).
- `reference-log.md` - reference, dataset, and visual verification log.
- `review-report.md` - review status and history.

## What Makes This Course Different from ASTR 101/120/210/230

This is the first upper-division astrophysics core course. Every physical law used here (the Planck function and the Stefan-Boltzmann/Wien laws it implies, the radiative transfer equation, the Boltzmann/Saha equations, hydrostatic equilibrium, the virial theorem, the reduced two-body problem and generalized Kepler's third law, tidal-force expansion and the Roche limit, the vis-viva equation, and the Eddington luminosity) is derived from first principles rather than presented as an applied formula, and every worked numeric example is computed programmatically from real astronomical data (principally the Alpha Centauri AB binary system) rather than hand-typed.
