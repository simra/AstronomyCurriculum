# Source Indexes

This folder contains lightweight indexes extracted from adopted source materials when exact references are needed for course artifacts.

## Purpose

Use a source index to verify exact readings, figures, exercises, and problem numbers before citing or assigning them. Do not treat generated indexes as a replacement for human review of the adopted edition.

## Current Indexes

- `openstax-astronomy-2e-problem-index.json` - machine-readable exercise index generated from the local OpenStax Astronomy 2e PDF text extraction.
- `openstax-astronomy-2e-problem-index.md` - human-readable version of the same exercise index.

## Use

When recommending textbook problems:

1. Search the relevant source index for candidate exercises.
2. Cite the source title, exercise type, problem number, and extracted line number or excerpt.
3. Verify final numbering against the adopted textbook edition before instructional release.

This pattern can be reused for other textbooks or source materials only when exact source references are needed.
