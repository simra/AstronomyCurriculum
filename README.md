# Astronomy Curriculum

This repository contains a draft undergraduate astronomy curriculum intended for review and iterative development.

## Current Phase

Phase 1 creates a four-year course list with course calendar-style entries, including course numbers, titles, credit hours, prerequisites, and brief syllabus descriptions.

## Files

- `astronomy_curriculum.html` - HTML document containing the draft four-year degree plan and course catalog entries.
- `.github/copilot-instructions.md` - Workspace guidance for future curriculum development work.

## Next Phase

After review, the curriculum can be expanded into detailed weekly schedules, learning objectives, assessments, lab activities, and resource lists.
